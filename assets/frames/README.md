# Hero frame sequence (test 01)

**What's here now:** a 48-frame placeholder sequence (`hero-0001.jpg` …
`hero-0048.jpg`), generated by slowly pushing in and panning across
`assets/img/path-machining.jpg`. It exists so the scroll-film mechanic is
reviewable end to end — it is not the real hero video.

## Replacing it with the real sequence

1. Export the hero video to stills into this folder.
2. Set `FRAMES.COUNT` in `tests/01-video-scroll/test.js` to the frame count.
3. If your naming differs, adjust `FRAMES.FILE` in the same file.

Expected naming by default:

    hero-0001.jpg
    hero-0002.jpg
    ...

## Notes

- Around 100–160 frames at ~1600px wide is usually the right trade between
  smoothness and weight. Keep every frame the same pixel dimensions.
- The scroll track length is derived from the frame count via
  `SVH_PER_FRAME`, clamped between `MIN_SVH` and `MAX_SVH`, so a longer
  sequence automatically gets a longer hero scroll.
- Setting `COUNT: 0` drops back to the flat backdrop.
- Frames are preloaded up front. The first frame to arrive swaps the flat
  plate out, and the rest fill in behind it.
